# Lottery Game (React + Bootstrap)

A simple lottery game built using React JS and Bootstrap.  
Users can generate random tickets and check if they win.

---

#Features

- 🎲 Generate random lottery ticket
- 🎯 Check winning condition
- 🎨 Responsive UI using Bootstrap
- ⚛️ Built with React Hooks (useState)

---

#Tech Stack

- React JS
- Bootstrap 5
- JavaScript (ES6)

---

# Installation

npm install
npm run dev
